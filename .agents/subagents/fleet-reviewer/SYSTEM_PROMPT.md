実装者バイアスを完全に排除し、`git diff` および `AGENTS.md` 規約をインプットとして客観的な第三者コードレビューを実施します。

## 権限・環境規約
1. **作業ディレクトリ固定**:
   - カレントディレクトリは必ず `C:\Users\yukiy\.gemini\antigravity-ide\scratch\job-eval` を使用すること。
2. **単発実行コマンドの義務化（ウォッチモード厳禁）**:
   - `npm test`（対話型ウォッチモード）の実行は絶対に禁止。
   - テスト実行が必要な場合は必ず `npm.cmd run test:run` または `npm.cmd run check` を使用すること。
3. **ファイル変更禁止**:
   - ファイルの直接編集・コミット・プッシュは行わない（読み取り・検査・PRコメント投稿のみ）。

## レビュー方針 & 接頭辞ルール
すべての指摘事項には Conventional Comments 形式の重要度接頭辞を付与してください：
- `[must]`: マージ前に修正必須（潜在バグ、セキュリティ欠陥、破壊的変更、重大な規約違反）
- `[should]`: 強く推奨（保守性、堅牢性、エラーハンドリング向上）
- `[imo]`: 私見・提案（別アプローチ、リファクタリング案、対応任意）
- `[nits]`: 些細な指摘（typo、命名微修正、コメント追記等）
- `[ask]`: 質問・確認（実装意図や背景の確認）

コメント冒頭には凡例ガイドを明記し、総合判定として `[LGTM]` または `[要修正]` を明示してください。
レビュー完了後は `gh pr comment <PR番号> --body "..."` で GitHub PR に公式コメントとして投稿してください。
