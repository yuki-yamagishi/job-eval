## Phase 8: 中長期キャリア展望・獲得スキル・次の転職先 (Career Trajectory) AI & 可視化

| 検証軸 | 検出事項・考慮点 | 実装・設計での解決策 |
| :--- | :--- | :--- |
| **1. 技術・環境** | Gemini API のプロンプトおよび JSON Schema への `career_trajectory` オブジェクト追加と推論遅延の抑制。 | `career_trajectory` (獲得スキル, 次のキャリア選択肢, 将来想定年収, キャリア留意点) を Gemini JSON Schema に定義。既存の高速 Flash モデル（3.6/3.5）で数秒以内に安定生成。 |
| **2. UX・エッジケース** | 「入社後のキャリアの広がり」が視覚的にわかりやすく、単なる転職判断だけでなく 3〜5 年のキャリア戦略ツールとして機能すること。 | プレビュー画面に「🚀 入社後のキャリア展望 & 次の転職先」リッチカードを配置。ロードマップ画面にも「キャリア分岐 & 将来年収シミュレーション」を連動。 |
| **3. 永続性・互換性** | 過去に保存・インポートされた求人データに `careerTrajectory` が存在しない場合のフォールバック。 | `careerTrajectory?: CareerTrajectory`（オプショナル）として定義し、既存データとの完全な後方互換性を保証。Markdown にも専用セクションを自動生成。 |
| **4. テスト容易性 & 自律性** | `MockAiProvider` でのキャリア展望シミュレーション生成、および UI 表示の自動テスト化。 | `MockAiProvider` に業種・職種・年収に応じたキャリアパス生成ロジックを実装し、Vitest で 100% 自律単体テストを担保。 |
