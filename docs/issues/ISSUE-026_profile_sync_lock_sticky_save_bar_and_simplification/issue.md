# [Improvement / Bug] プロファイル設定画面の編集中同期リセット防止、スマホ向け常時固定保存バー導入、およびプロファイル同期のシンプル化（マージ廃止・クラウド正）

- **ステータス**: 🔵 着手可能 (`status: ready`)
- **優先度**: 最優先 (High / Usability & Architecture)
- **カテゴリ**: `type: bug`, `type: feature`, プロファイル, UI/UX, モバイル, 同期アーキテクチャ
- **対象プラットフォーム**: 全プラットフォーム (Web / Mobile / Desktop)

## 📌 課題の概要 (Problem Description)

ユーザーから以下の 3 つの重大なユーザビリティ・アーキテクチャ課題が指摘された：

1. **設定変更中に同期が走って勝手に元に戻される**:
   - ユーザーがプロファイル設定画面でスキルや資格を編集・削除している最中に、バックグラウンドの同期（D1 20秒ポーリングまたは P2P）が走り、親コンポーネントの `profile` ステート更新に伴って `ProfileSettingsView` の `draft` が強制リセットされ、編集中の作業が吹き飛んでしまう。
2. **スマホで保存ボタンを押すために上までスクロールしなければならず不便**:
   - 保存ボタンが最上部のヘッダーにしか配置されておらず、スマートフォンでスキルや資格、希望条件を縦スクロールして編集した後、わざわざ一番上までスクロールバックしなければ保存できない。
3. **プロファイルにおける「スマートマージ」の無用な複雑さ**:
   - データの実体はクラウド D1 に集約されているにもかかわらず、端末側で「古いプロファイルと新しいプロファイルのマージ（和集合）」などを行うため、削除した項目が復活する等の不具合の温床となっていた。プロファイルはクラウド D1 の最新レコードを正（Single Source of Truth）とし、複雑なマージを廃止して最新優先（LWW・完全代入）にシンプル化すべきである。

---

## 🎯 要件定義 (Requirements)

### 1. 編集中（isDirty）保護機能の導入 (`src/features/profile/ProfileSettingsView.tsx`)
- ユーザーが編集を開始した場合（`isDirty = true`）、バックグラウンドで `profile` が更新されても `draft` を上書きしないよう保護ガードを実装。
- 初回ロード時、または明示的にユーザーが保存・リセットを完了した時のみ同期する。

### 2. スマホ・デスクトップ両対応 Sticky Bottom Action Bar（常時固定保存バー）の導入
- 画面最下部に固定表示（`fixed bottom-0 left-0 right-0`）される保存バーを新設。
- 未保存の変更がある場合は「● 未保存の変更があります」とバッジ表示し、どの位置までスクロールしていてもワンタップで「💾 プロファイルを保存」できる。
- 保存処理中（ローディングスピナー）や最終保存時刻も直感的に表示。

### 3. プロファイル同期のシンプル化（スマートマージ廃止・クラウドDB正）(`src/core/sync/smartMerge.ts`)
- プロファイルに対する「スマートマージ（和集合）」を完全撤廃。
- プロファイルは単一設定ドキュメントとして、最新のタイムスタンプを持つプロファイルをそのまま採用（LWW）。
- 保存時は即座にローカルストレージ更新＋D1 へプッシュし、D1 側が即座に最新となる設計にする。
