## Phase 27: プロジェクト実績の解像度向上: 担当開発工程選択 ＆ 複数STARエピソード管理 (Issue #29)

| 検証軸 | 検出事項・考慮点 | 実装・設計での解決策 |
| :--- | :--- | :--- |
| **1. 技術・環境** | `ProjectExperience` 型に `phases` と `starEpisodes` を追加し、既存データとの後方互換性を保つ。 | 既存の単一 `situation/action/result` が存在する場合は自動で最初の `starEpisodes` にマイグレーションするフォールバックを実装。 |

| **4. テスト容易性 & 自律性** | 担当工程バッジのトグル、複数STARエピソードの追加・削除のテスト。 | `CareerHistoryView.test.tsx` に工程選択と複数STARエピソード追加のテストケースを拡充。 |
