# [Issue] 求人・プロファイルデータのスマートマージ（ID突合＆差分自動統合）とコンフリクト解消の実装

- **ステータス**: オープン (To Do)
- **優先度**: 高 (High)
- **カテゴリ**: データ同期, ストレージ整合性, コアロジック (Pure Function)
- **対象プラットフォーム**: 全プラットフォーム (Web / Mobile / Desktop)

---

## 📌 課題の概要 (Problem Description)

リアルタイム同期時や端末間ペアリング時において、PCとスマートフォンの双方がそれぞれローカルで求人データやプロファイルを編集・保持していた場合（例: PCに求人A・Cがあり、スマホに求人A・Bがある場合）、単純な上書き同期を行うと片方のデータが消失するリスクが存在する。

本 Issue では、**IDベースのスマートマージ（重複排除・差分統合・最新日時優先のコンフリクト解消）アルゴリズム** を純粋関数として実装し、どちらの端末から同期を開始しても求人・プロファイルデータが欠落せず完全に統合される安全性を確立する。

---

## 🎯 要件定義 (Requirements)

### 1. 求人リストのスマートマージ (`mergeJobs`)
- `localJobs` と `remoteJobs` を受け取り、ユニークID（`metadata.id`）をキーとして統合。
- **同一IDの求人が両端末に存在する場合**:
  - 更新日時（`metadata.updatedAt` または `metadata.analysisDate`）がより新しい側の求人データを採用。
  - 評価履歴（`evaluationHistory`）が存在する場合は、履歴アイテムもID・日時ベースで重複排除してマージ。
- **片方の端末にのみ存在する求人**: そのまま結果リストに保持（データ消失ゼロ）。
- **ソート順**: 解析日・更新日の降順を維持。

### 2. プロファイルデータのスマートマージ (`mergeProfile`)
- `localProfile` と `remoteProfile` のタイムスタンプ（`updatedAt`）を比較し、最新版をベースに統合。
- スキルリスト（`skills`）および保有・学習中資格リスト（`certifications`）は、ID/名称ベースで重複排除マージ。
- API設定（APIキー等）は、キーが設定されている側を安全に優先採用。

### 3. ストレージ層への自動マージ組み込み
- リモート端末から同期通知を受信した際、受信側ローカルストレージ内の既存データと自動マージを実行した上で保存・描画更新。
