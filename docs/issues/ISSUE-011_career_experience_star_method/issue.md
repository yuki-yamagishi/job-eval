# [Feature / Backlog] 職務経歴・プロジェクト実績（STAR法誘導＆AIアシスト）の管理機能と求人評価コンテキスト連携

- **ステータス**: 🟡 バックログ (Backlog / 未着手)
- **優先度**: 中 (Medium)
- **カテゴリ**: 職務経歴, ユーザーコンテキスト, AI評価精度向上, UI/UX
- **対象プラットフォーム**: 全プラットフォーム (Web / Mobile / Desktop)

---

## 📌 課題の概要 (Problem Description)

転職市場における実際の評価基準は、単なる保有スキル名や資格（例: AWS認定など）よりも、**「実務においてどのような役割で、どのような課題に直面し、何を成し遂げてきたか（実績・ビジネスインパクト）」** が極めて重視される。

現在の JobEval はスキル一覧や希望条件の管理が中心であり、ユーザーの過去のプロジェクト実績・職務経歴エピソードを詳細にコンテキストとして保持・活用する仕組みが不足している。
また、大きなフリーテキストエリアでの入力はユーザーにとって心理的ハードルが高く、何をどう書けばよいか迷いやすい課題がある。

---

## 🎯 要件定義 (Requirements)

### 1. 第5のメインナビゲーションタブ「📄 職務経歴・実績」の新設
- ヘッダーに専用タブを配置し、職務経歴・プロジェクト実績の閲覧・追加・編集・並び替えを快適に行える専用ビューを提供。
- 入力された実績一覧から **「職務経歴書（Markdown）」** をワンクリックでプレビュー・クリップボードコピー・エクスポートできる機能。

### 2. STAR法（状況・行動・成果）による構造化入力フォーム
- 穴埋め感覚で誰でもスラスラ書ける以下の入力フィールドを用意：
  - **会社名 / 期間**: （例: 株式会社〇〇 / 2023年4月 〜 現在）
  - **プロジェクト名 / 業務概要**: （例: ECサイトの大規模リプレイスとAPI刷新）
  - **役割 / チーム規模**: （例: テックリード / 8名）
  - **使用技術スタック**: （タグ選択・自由入力）
  - **📌 直面した課題・背景 (Situation & Task)**: 課題や前提条件
  - **💡 自身が取った行動・工夫 (Action)**: 主導した施策、技術的工夫
  - **🏆 達成した成果・定量的インパクト (Result)**: 数値実績、ビジネス貢献度

### 3. AI実績ブラッシュアップ（壁打ち・文章整形アシスト）
- 断片的な箇条書きやメモを入力して「✨ AI整形」ボタンを押すと、Gemini API と連携して魅力的で簡潔なビジネス文章に自動リライト・要約する機能。

### 4. AI求人適合度評価プロンプトへの実績コンテキスト注入
- 求人解析時、ユーザーの直近の主要プロジェクト実績をプロンプトの `【候補者コンテキスト】` に注入。
- AIが「この求人の求める〇〇という課題に対し、過去の〇〇実績（レイテンシ削減・チームリード経験等）が強く活きる」と、超具体的かつ説得力のある講評を生成できるようにする。

---

## ✅ 受け入れ基準 (Acceptance Criteria)

- [ ] プロジェクト実績を STAR 形式でカード追加・編集・削除・並び替えができること。
- [ ] 入力された実績がローカルストレージおよび端末間同期で安全に永続化されること。
- [ ] 求人解析プロンプトに実績データが反映され、求人票の業務内容と過去実績を照合した具体的な講評が出力されること。
- [ ] 職務経歴書 Markdown として出力できること。
