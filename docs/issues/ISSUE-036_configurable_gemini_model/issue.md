# ISSUE-036: AI PR レビューのデフォルトモデル最適化とRPDクォータ上限回避

## 1. 概要
AI PR レビューボットの利用モデルを、日次クォータ（RPD）の制限が厳しいモデルから、高頻度な開発 push に耐えうる最新の軽量高速モデル `gemini-3.5-flash-lite` へと刷新しました。

## 2. 主な変更点
1. **デフォルトモデルの最適化**:
   - `gemini-3.5-flash-lite` をメインに採用（日次クォータ 500〜1,500 回/日を確保し、日中頻繁なコミットでもクォータ枯渇リスクを防止）。
2. **多段フォールバックの整備**:
   - `gemini-3.5-flash-lite` ➔ `gemini-3.1-flash-lite` の順でフォールバック。
3. **環境変数連携**:
   - GitHub Actions ワークフローおよびスクリプトで `GEMINI_MODEL` 環境変数による任意モデルのオーバーライドを正式サポート。
4. **単体テスト対応**:
   - `tests/scripts/aiPrReviewer.test.ts` を新モデルおよび戻り値構造に合わせて更新。

## 3. 検証結果
- `npm.cmd run check` 100% PASS。
