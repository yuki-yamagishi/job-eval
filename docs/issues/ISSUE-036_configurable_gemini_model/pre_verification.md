## Phase 31: AI PR レビューのデフォルトモデル最適化とRPDクォータ上限回避 (PR #36)

| 検証軸 | 検出事項・考慮点 | 実装・設計での解決策 |
| :--- | :--- | :--- |
| **1. 技術・環境** | 最上位モデルの RPD 上限（20〜50回/日）により CI が頻繁に 429 エラーになるリスク。 | 日次 500〜1,500 回の `gemini-3.5-flash-lite` をデフォルトとし、`gemini-3.1-flash-lite` へのフォールバックを実装。 |
