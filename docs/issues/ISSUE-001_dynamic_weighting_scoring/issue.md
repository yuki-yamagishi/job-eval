# ISSUE-001: ユーザー志向に応じた4軸評価の動的重み付けカスタマイズ＆保存済求人の一括・リアルタイム再計算機能

## 1. 課題・背景
ユーザーの転職動機（リスキリング重視、WLB重視、年収最大化など）によって、求人評価の重視項目が異なります。
固定配分（スキル40%/条件30%/成長20%/環境10%）だけでなく、ユーザーが動的に重みを調整・シミュレーションできる仕組みを提供します。

## 2. 要件定義
1. **重み付けプロファイル & プリセット管理 (`UserProfile`)**:
   - 標準バランス型、リスキリング・成長重視、カルチャー・環境重視、待遇・条件最優先、カスタム配分。
2. **クライアントサイド高速再計算エンジン (`src/core/scoring/`)**:
   - 保存済みのブレイクダウンから決定論的に総合スコアを再計算する `recalculateScoreWithWeights`。
3. **UIでのリアルタイム視点切り替え・シミュレーション機能**:
   - `PreviewPane` および `Dashboard` での視点切り替えピル。
4. **一括更新＆Markdown同期機能**:
   - 保存済み全求人の Frontmatter 一括更新。

## 3. 受け入れ基準
- [x] `UserProfile` に `scoringWeights` 設定が保持・永続化されること。
- [x] `recalculateScoreWithWeights` により決定論的スコア再計算ができること。
- [x] プレビュー画面・ダッシュボードで視点切り替えができること。
- [x] `npm run check` が 100% PASS すること。
- [x] ADR-0004 が作成されること。
