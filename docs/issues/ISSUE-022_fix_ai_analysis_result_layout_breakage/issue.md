# [Bug] AI解析後プレビュー画面（PreviewPane）におけるヘッダーアクション・スコア内訳・カード群の表示レイアウト崩れの修正

- **ステータス**: 🔵 着手可能 (`status: ready`)
- **優先度**: 高 (High / Bug)
- **カテゴリ**: `type: bug`, UI/UX, レスポンシブ, プレビュー画面
- **対象プラットフォーム**: 全プラットフォーム (Web / Mobile / Desktop)

---

## 📌 課題の概要 (Problem Description)

求人を入力して AI 解析を実行した後、または保存済み求人を選択して詳細を表示した際、右ペイン（`PreviewPane.tsx`）において以下の表示レイアウト崩れが発生していた：

1. **Top Bar アクションヘッダーのはみ出し・重なり**:
   - `h-12`（高さ48px固定）のヘッダー内に、左側の「企業名・ファイル名・ステータスバッジ」と、右側の「表示切替トグル（3つ）・全文コピー・最新プロファイルで再評価・Obsidian/Vault保存」という多数のボタンが横一列に詰め込まれていた。
   - 2ペイン表示時（右ペイン幅が約 600px〜800px の場合）やモバイル画面において、右側のボタン群が左側のタイトルと衝突してはみ出し、下のコンテンツと重なってしまう。
2. **スコアサマリーカードの衝突**:
   - 求人タイトルが長い場合、右側の「総合適合スコア（3xlフォント）」と衝突してテキストやバッジが押し潰される。
3. **スコア内訳バーの狭幅崩れ**:
   - `grid-cols-4` 固定のため、狭幅表示時に各要素の幅が 70px 程度となり、`スキル合致 (40%)` などの文字が不自然に折れ曲がって表示される。
4. **ポジティブ要素と懸念点の 2 カラム固定崩れ**:
   - `grid-cols-2` 固定のため、狭幅で各カードの横幅が不足し、箇条書きの文章が極端に縦長に崩れる。
5. **スプリット編集モードの多重スクロール崩れ**:
   - `h-[calc(100vh-140px)]` の固定計算により、ヘッダーがレスポンシブに高さを変えた際に画面外へ突き抜ける。

---

## 🎯 要件定義 (Requirements)

### 1. Top Bar アクションヘッダーのレスポンシブ最適化 (`src/components/pane/PreviewPane.tsx`)
- ヘッダー高さを `min-h-12 py-2` のフレキシブルレイアウトに改修し、ボタン群が重ならず自然に配置されるようにする。
- 狭幅画面ではファイル名を省略・短縮し、主要アクション（保存・表示切替・再評価）が崩れずに整然と並ぶようにする。

### 2. サマリースコアカード & スコア内訳のレスポンシブ化
- スコアサマリーヘッダーを `flex flex-col sm:flex-row items-start sm:items-center justify-between gap-3` に改修。
- スコア内訳バーを `grid grid-cols-2 sm:grid-cols-4 gap-2` に改修し、スマホや狭画面でも読みやすい 2 列折り返しに対応。

### 3. ポジティブ要素 & 懸念点カードのレスポンシブ化
- `grid-cols-2` から `grid grid-cols-1 md:grid-cols-2 gap-3` に改修。

### 4. スプリット編集・Raw モードのコンテナサイズ最適化
- `flex-1 min-h-0` によるフレックスボックス伸縮に移行し、画面外突き抜けを防止。
