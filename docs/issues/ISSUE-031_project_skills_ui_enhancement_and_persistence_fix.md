# [Bug & UI/UX] プロジェクト使用技術・スキルスタックの保存消失バグ修正 ＆ 資格・スキル設定に準拠した追加UIへの刷新

- **ステータス**: 🔵 着手可能 (`status: ready`)
- **優先度**: 最高 (Critical / Bug Fix & UX Enhancement)
- **カテゴリ**: `type: bug`, `type: feature`, UI/UX, 職務経歴, スキル入力
- **対象プラットフォーム**: 全プラットフォーム (Web / Mobile / Desktop)

---

## 📌 課題の概要 (Problem Description)

職務経歴・プロジェクト実績の編集モーダルにおいて、以下の問題が発生している：
1. **入力中テキストの保存消失**: スキル名を入力した状態で「Enter」を押さずに「プロジェクトを保存」ボタンを押すと、入力中のテキストが反映されずに消去・破棄される。またスマートフォン環境ではソフトウェアキーボードの確定操作で Enter イベントが正しく発火しないケースがある。
2. **UI/UXの不整合**: プロファイル設定の資格・スキル入力欄では「一覧エリア」＋「入力欄＋独立した『＋追加』ボタン」＋「カンマ区切り一括登録」が提供されているのに対し、プロジェクト編集モーダルでは単一のインライン入力タグ形式となっており、追加ボタンがなくモバイルでの操作性が悪い。

---

## 🎯 要件定義 (Requirements)

### 1. 資格・スキル設定準拠のUIへの刷新
- プロファイル設定画面の「認定資格 & 目標資格」UIに準拠したコンポーネント構造に変更：
  - **スキル一覧バッジエリア**: 登録されたスキルをバッジ＋×削除ボタンで一覧表示。未登録時は「使用技術・スキルがまだ登録されていません」と案内。
  - **独立した追加用コントロール**: `Input` と `Button（＋ 追加）` を横並びで配置。
  - **カンマ/空白区切り一括登録**: `Go, AWS, Docker` のようにカンマ区切りで入力しても一度に分割登録可能に。
  - **クイック候補チップ**: プロファイルに登録されている自身のスキル（`profile.skills`）を候補バッジとして表示し、タップするだけでプロジェクトに即座に追加できる支援機能。

### 2. 未追加入力の自動保存ガード（消失バグ防止）
- 「プロジェクトを保存」ボタンが押された際、もし `projectSkillInput` に入力途中の文字列が残っていれば、自動的に `skills` に追加してから親コンポーネントへ保存する安全機構を実装。
