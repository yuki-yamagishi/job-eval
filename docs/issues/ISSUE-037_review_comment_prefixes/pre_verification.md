## Phase 32: AI レビュー指摘への重要度プレフィックス（[must], [should], [imo]等）義務化 (PR #37)

| 検証軸 | 検出事項・考慮点 | 実装・設計での解決策 |
| :--- | :--- | :--- |
| **1. 技術・環境** | AIレビューの指摘が重要（必須修正）なのか提案なのか一目で判別できない。 | プロンプトで `[must]`, `[should]`, `[imo]`, `[nits]`, `[ask]` の接頭辞付与を義務化。 |
| **2. UX・エッジケース** | 接頭辞の意味が開発者に伝わらない可能性。 | コメント最上部に凡例ガイド（Blockquote）を自動挿入。総合判定 `[LGTM]` / `[要修正]` を明示。 |
| **3. 永続性・互換性** | 過去のレビューコメントとの整合性。 | 既存の PR コメントタグ `<!-- AI-PR-REVIEW-BOT -->` と構造を維持し完全互換。 |
| **4. テスト容易性 & 自律性** | 接頭辞ルールがプロンプトと出力コメントに正しく反映されることの検証。 | `tests/scripts/aiPrReviewer.test.ts` にアサーションを追加し、`npm.cmd run check` で 100% 検証。 |
