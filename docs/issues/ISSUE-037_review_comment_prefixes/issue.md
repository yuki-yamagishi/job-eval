# ISSUE-037: AI レビュー指摘への重要度プレフィックス（[must], [should], [imo]等）義務化

## 1. 概要
AI レビューボットの各指摘事項について、対応必須度・重要度を一目で判別可能にするため、標準レビュー接頭辞（Conventional Comments スタイル）を義務化しました。

## 2. 主な変更点
1. **レビュープロンプトへの接頭辞義務化ルール追加**:
   - `[must]`: マージ前に修正必須
   - `[should]`: 強く推奨
   - `[imo]`: 私見・提案
   - `[nits]`: 些細な指摘
   - `[ask]`: 質問・確認
   - 総合判定として `[LGTM]` または `[要修正]` を明示。
2. **PR レビューコメント冒頭への凡例ガイド追加**:
   - コメント上部に接頭辞の意味を説明するブロッククォートを自動挿入。
3. **テストの拡充**:
   - 単体テスト追加。

## 3. 検証結果
- `npm.cmd run check` 100% PASS。
